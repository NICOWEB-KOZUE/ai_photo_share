## 確認方法

- 手動確認と重要部分のpytestを併用する。T03以降、該当機能の制約・認証・権限のテストを実装と一緒に追加する。
- 初めてテストを書くときにpytestを開発用依存へ追加する。テストは一時DB・一時画像フォルダ・一時セッション保存先を使用する。
- `Alice` と `alice` は登録可能、`Alice` の再登録と ` Alice ` は拒否。メールの前後空白・大小文字も確認する。
- 画像は正常なJPEG・PNG、偽装ファイル、破損、容量の境界、EXIF除去を確認する。
- 他人の削除・CSRFなしのPOST・未ログイン投稿を拒否する。期限テストは時刻を制御し、24時間待たない。
- 成功後の再読み込みでフォームが再送信されないことを確認する。
- 手動確認できないものは「未確認」と記録する。未実施の確認を成功扱いにしない。
